# نصب و راه‌اندازی

## پیش‌نیازها

- Node.js نسخهٔ ۲۰ یا بالاتر
- ایمیل و گذرواژهٔ TheyPaid برای اتصال و راه‌اندازی حساب و فروشگاه
- گذرواژهٔ جداگانه برای کیف‌پول محلی، فقط در صورت ساخت کیف‌پول؛ حداقل ۱۶ نویسه

## نصب

~~~sh
git clone https://github.com/plilian/crypto-payment-gateway-farsi.git
cd crypto-payment-gateway-farsi
npm install
npm run build
~~~

تا زمان انتشار بسته در npm، سرور MCP را با اجرای فایل خروجی راه‌اندازی کنید:

~~~sh
node /مسیر/کامل/پروژه/dist/mcp/index.js
~~~

## اطلاعات ورود

متغیرهای زیر را در محیط امن فرایند MCP یا Secret Store برنامهٔ میزبان تنظیم کنید. گذرواژه و کلید را در پیام‌ها یا ورودی ابزارها ننویسید.

~~~text
THEYPAID_ACCOUNT_EMAIL=merchant@example.com
THEYPAID_ACCOUNT_PASSWORD=<secret>
THEYPAID_WALLET_PASSWORD=<separate-secret>
~~~

متغیرهای اختیاری:

- `THEYPAID_ACCESS_TOKEN`: توکن داشبورد برای بعضی درخواست‌های حساب
- `THEYPAID_2FA_CODE`: کد شش‌رقمی ورود دومرحله‌ای
- `THEYPAID_API_KEY`: کلید API فروشگاه
- `THEYPAID_STORE_ID`: محدودکردن کلید API به فروشگاه مشخص
- `THEYPAID_WALLET_DIR`: مسیر ذخیرهٔ امن فایل کیف‌پول

نشست حساب و کلید API ساخته‌شده در حافظهٔ همان فرایند MCP می‌مانند و با بستن یا راه‌اندازی دوبارهٔ آن پاک می‌شوند. در صورت استفاده از کلید ازپیش‌ساخته، آن را همراه شناسهٔ فروشگاه در Secret Store قرار دهید.

## پیکربندی MCP

نمونهٔ زیر را با مسیر واقعی فایل خروجی و روش مدیریت Secret در برنامهٔ خود تطبیق دهید:

~~~json
{
  "mcpServers": {
    "theypaid": {
      "command": "node",
      "args": ["/absolute/path/to/crypto-payment-gateway-farsi/dist/mcp/index.js"],
      "env": {
        "THEYPAID_ACCOUNT_EMAIL": "",
        "THEYPAID_ACCOUNT_PASSWORD": "",
        "THEYPAID_WALLET_PASSWORD": ""
      }
    }
  }
}
~~~

این سرور از ارتباط MCP از نوع stdio استفاده می‌کند. همین فرمان در Codex، کلاینت‌های سازگار با Claude و OpenClaw قابل استفاده است. برای جزئیات اختصاصی هر میزبان، راهنمای رسمی آن را ببینید: [Codex](https://developers.openai.com/codex/config-reference) · [Claude Code](https://code.claude.com/docs/en/mcp) · [OpenClaw](https://docs.openclaw.ai/tools/mcp).

## نصب Skill

فایل `skill/theypaid/SKILL.md` را در پوشهٔ Skill محیط خود کپی کنید:

- OpenClaw: `<workspace>/skills/theypaid/SKILL.md`
- Codex: `~/.codex/skills/theypaid/SKILL.md`
- Claude Code: `.claude/skills/theypaid/SKILL.md` یا مسیر Skill کاربر

Skill برای دسترسی به حساب و پرداخت به سرور MCP نیاز دارد.

## شروع کار با عامل

1. برای حساب تازه، عامل `theypaid_register_account` را اجرا می‌کند. سپس ایمیل تأیید TheyPaid را باز کنید و ثبت‌نام را تأیید کنید.
2. با `theypaid_connect_account` وارد حساب شوید. اگر ورود دومرحله‌ای فعال است، کد همان لحظه را وارد کنید.
3. با `theypaid_list_stores` فروشگاه‌ها را بررسی کنید؛ در صورت نیاز فروشگاه را بسازید و انتخاب کنید.
4. فهرست دارایی‌ها را بگیرید. کیف‌پول موجود را با نشانی عمومی یا xpub وصل کنید، یا کیف‌پول محلی بسازید و پیش از ثبت آن تأییدتان را بدهید.
5. کلید API فروشگاه را بسازید یا کلید موجود را به‌صورت امن تنظیم کنید.
6. اعتبار خدماتی و دارایی‌های فعال فروشگاه را ببینید. فقط هنگام درخواست شما، عامل فاکتور یا لینک پرداخت ایجاد می‌کند.

## امنیت کیف‌پول

ابزار کیف‌پول فقط برای دارایی‌های فهرست‌شده در تنظیمات فروشگاه TheyPaid کیف‌پول می‌سازد. اطلاعات بازیابی رمزگذاری‌شده روی همان میزبان MCP ذخیره می‌شود؛ نشانی عمومی یا xpub به عامل و TheyPaid داده می‌شود.

از فایل رمزگذاری‌شده و مقدار `THEYPAID_WALLET_PASSWORD` جداگانه نسخهٔ پشتیبان بگیرید. هرگز عبارت بازیابی یا کلید خصوصی را برای TheyPaid، عامل یا ابزار MCP نفرستید.

برای بازیابی عبارت، فقط در ترمینال امن و محلی خود فرمان زیر را اجرا کنید. خروجی این فرمان عبارت بازیابی را نشان می‌دهد:

~~~sh
theypaid-wallet-recover <wallet-file>
~~~

## رفع اشکال

- **اطلاعات ورود تنظیم نشده:** ایمیل و گذرواژه را در محیط امن فرایند MCP تنظیم و میزبان را دوباره راه‌اندازی کنید.
- **تأیید ایمیل:** پیش از ورود به حساب تازه، ایمیل تأیید TheyPaid را باز کنید.
- **ورود دومرحله‌ای:** کد شش‌رقمی تازه را وارد کنید؛ آن را در گفت‌وگو یا فایل ماندگار ذخیره نکنید.
- **فروشگاه یا کلید اشتباه:** فروشگاه درست را انتخاب کنید و مطمئن شوید کلید API به همان فروشگاه تعلق دارد.
- **خطای ۴۰۱ یا ۴۰۳:** اعتبار کلید را در TheyPaid بررسی یا در صورت نیاز تعویض کنید.
- **ردشدن دارایی یا کیف‌پول:** شبکه و دارایی انتخابی را با فهرست TheyPaid و نشانی عمومی کیف‌پول تطبیق دهید.
- **پاسخ‌نگرفتن هنگام ساخت فاکتور:** پیش از تلاش دوباره، فهرست فاکتورها را بررسی کنید تا فاکتور تکراری ساخته نشود.
- **منقضی‌شدن لینک:** برای پرداخت جدید، از TheyPaid لینک تازه بسازید.
