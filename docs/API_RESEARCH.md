# مرجع API و SDK TheyPaid

این یکپارچه‌سازی به سرویس پرداخت TheyPaid وصل می‌شود. خود TheyPaid فاکتور را مدیریت می‌کند، شبکهٔ بلاک‌چین را پایش می‌کند، تراکنش را تشخیص می‌دهد و وضعیت پرداخت را به‌روزرسانی می‌کند. MCP درخواست‌ها را می‌فرستد و پاسخ رسمی سرویس را به عامل برمی‌گرداند.

## Merchant API

**نشانی پایه:** https://merchant.theypaid.io
**احراز هویت:** کلید API فروشگاه در Header با نام apiKey. کلید هر فروشگاه به همان فروشگاه محدود است.

| روش و مسیر | ورودی | کارکرد |
|---|---|---|
| POST /invoice | assetId، amountInTether، acceptToleranceInTether؛ و به‌صورت اختیاری requiredConfirmations، description، callbackUrl و redirectUrl | ساخت فاکتور و دریافت شناسه، دارایی، مبلغ، نشانی پرداخت، وضعیت، زمان انقضا و paymentLink |
| GET /invoice/{invoiceId} | شناسهٔ فاکتور در مسیر | دریافت جزئیات فاکتور، مبلغ پرداخت‌شده، تراکنش‌ها، وضعیت و زمان‌ها |
| POST /invoice/{invoiceId}/recheck | شناسهٔ فاکتور در مسیر | درخواست بررسی دوبارهٔ فاکتور توسط TheyPaid |
| GET /store/assets | کلید API فروشگاه | دریافت دارایی‌های فعال فروشگاه، شناسه، نماد، شبکه، نرخ و اطلاعات عمومی کیف‌پول |
| GET /store/invoices | offset و limit اختیاری | فهرست فاکتورهای همان فروشگاه |

نمونهٔ درخواست ساخت فاکتور:

~~~json
{
  "assetId": "bc6061b7-846a-4ca2-8c69-4b6515951fe2",
  "amountInTether": 100,
  "acceptToleranceInTether": 5,
  "requiredConfirmations": 3,
  "description": "Order #12345",
  "callbackUrl": "https://merchant.example/webhook",
  "redirectUrl": "https://merchant.example/thank-you"
}
~~~

فیلد acceptToleranceInTether در مستندات API اجباری است؛ MCP نیز آن را اجباری می‌گیرد. redirectUrl باید HTTPS باشد. در ساخت فاکتور، assetId را از فهرست دارایی‌های فعال همان فروشگاه بگیرید.

## SDK رسمی

بستهٔ npm با نام theypaid-sdk رابط TypeScript برای Merchant API فراهم می‌کند:

- invoices.create: ساخت فاکتور
- invoices.get: دریافت فاکتور
- invoices.recheck: درخواست بررسی دوباره
- invoices.list: فهرست فاکتورهای فروشگاه
- invoices.poll: پیگیری فاکتور تا رسیدن به وضعیت نهایی یا پایان مهلت
- store.assets: دریافت دارایی‌های فعال فروشگاه

این پروژه برای عملیات فاکتور از همین SDK استفاده می‌کند.

## وضعیت پرداخت و پایش شبکه

TheyPaid شبکه‌های پشتیبانی‌شده را برای فاکتور پایش می‌کند، تراکنش‌های منطبق را تشخیص می‌دهد و وضعیت فاکتور را به‌روز می‌کند. پاسخ وضعیت فاکتور، نتیجه‌ای است که ابزارهای پرداخت MCP در اختیار عامل می‌گذارند.

| وضعیت | معنی |
|---|---|
| WAITING | پرداخت هنوز به وضعیت نهایی نرسیده است؛ فاکتور در حال پایش است. |
| PAID | TheyPaid پرداخت را برای فاکتور تأیید کرده است. |
| INSUFFICIENT | پرداخت شناسایی‌شده با مبلغ موردنیاز فاکتور برابر نیست. |
| EXPIRED | مهلت فاکتور پایان یافته است. |

SDK امکان poll کردن را دارد. همچنین می‌توان برای callbackUrl اعلان دریافت کرد. پس از اعلان، وضعیت فاکتور را از TheyPaid بخوانید تا نتیجهٔ نهایی را بگیرید.

## حساب، فروشگاه و کیف‌پول

ابزارهای MCP به جریان حساب کاربری و داشبورد TheyPaid وصل می‌شوند و این عملیات را انجام می‌دهند:

- ثبت‌نام، ورود ایمیل و گذرواژه و ورود دومرحله‌ای
- فهرست‌کردن، ساخت، خواندن، ویرایش، انتخاب، فعال‌سازی، غیرفعال‌سازی و حذف فروشگاه
- دریافت فهرست دارایی‌ها و اتصال یا ویرایش کیف‌پول عمومی فروشگاه
- فعال‌سازی، غیرفعال‌سازی و حذف دارایی فروشگاه
- ساخت یا لغو کلید API محدود به فروشگاه

حساب تازه باید ایمیل تأیید TheyPaid را تأیید کند. کلید API و نشست حساب در حافظهٔ فرایند MCP نگه‌داری می‌شوند.

## اعتبار خدماتی و شارژ

اعتبار خدماتی TheyPaid برای کارمزد پردازش فاکتور مصرف می‌شود و رمزارز کیف‌پول پذیرنده نیست. حساب‌های تازهٔ واجد شرایط ممکن است ۱۰ دلار اعتبار خوش‌آمدگویی دریافت کنند؛ این اعتبار به کیف‌پول رمزارز واریز نمی‌شود.

ابزارهای MCP می‌توانند موجودی را از TheyPaid بخوانند، فاکتور شارژ بسازند و وضعیت فاکتور را دوباره بررسی کنند. پس از پرداخت فاکتور شارژ، موجودی تازه را از TheyPaid بخوانید.

## لینک پرداخت فروشگاه

لینک پرداخت میزبانی‌شده با عملیات فروشگاه در TheyPaid ساخته می‌شود. این عملیات برای دارایی فعال فروشگاه یک فاکتور واقعی می‌سازد و لینک pay.theypaid.io را برمی‌گرداند. زمان انقضای این جریان ۳۰ دقیقه است.

Merchant API نیز هنگام ساخت فاکتور، paymentLink برمی‌گرداند. هر دو روش از زیرساخت فاکتور و پایش پرداخت خود TheyPaid استفاده می‌کنند.

## دارایی‌های کیف‌پول محلی

ساخت کیف‌پول محلی فقط برای دارایی‌های پشتیبانی‌شده در انتخاب‌گر فعلی فروشگاه TheyPaid انجام می‌شود:

| دارایی | شبکه | قالب اتصال به فروشگاه |
|---|---|---|
| BTC | Bitcoin | zpub |
| BCH | Bitcoin Cash | xpub |
| LTC | Litecoin | xpub |
| BSV | Bitcoin SV | xpub |
| GRAM | TON | نشانی عمومی |
| DOGE | Dogecoin | xpub |
| TON_USDT | TON | نشانی عمومی |
| TRX | Tron | نشانی عمومی |
| TRON_USDT | Tron | نشانی عمومی |
| BNB | BNB Smart Chain | نشانی عمومی |
| BSC_USDT | BNB Smart Chain | نشانی عمومی |
| ETH | Ethereum | نشانی عمومی |
| ETH_USDC | Ethereum | نشانی عمومی |

کلید خصوصی و عبارت بازیابی روی میزبان MCP ساخته و در فایل محلی رمزگذاری می‌شوند. برای اتصال به TheyPaid فقط نشانی عمومی یا xpub لازم است. این یکپارچه‌سازی تراکنش ارسال نمی‌کند و موجودی کیف‌پول را مدیریت نمی‌کند.
