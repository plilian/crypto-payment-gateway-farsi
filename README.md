# درگاه پرداخت رمزارزی برای عامل‌های هوش مصنوعی

**یکپارچه‌سازی TheyPaid با MCP و Skill عامل هوش مصنوعی**

این پروژه راهی برای کار با درگاه پرداخت موجود TheyPaid از داخل گفت‌وگو با عامل هوش مصنوعی است. ساخت فاکتور و لینک پرداخت، پایش شبکه، تشخیص تراکنش و تعیین وضعیت پرداخت را خود TheyPaid انجام می‌دهد؛ این یکپارچه‌سازی درخواست‌ها را به سرویس TheyPaid می‌رساند و نتیجه را در اختیار عامل می‌گذارد.

> **پروژه مستقل است.** این مخزن وابسته به TheyPaid نیست و از سوی این شرکت ساخته، تأیید یا پشتیبانی نمی‌شود. سازندگان و نگه‌دارندگان آن نماینده یا عضو تیم TheyPaid نیستند.
>
> سرویس TheyPaid غیرامانی است و برای استفاده از آن KYC لازم نیست. پرداخت مشتری مستقیم به کیف‌پول پذیرنده می‌رود. [وب‌سایت TheyPaid](https://theypaid.io) · [راهنمای مدل غیرامانی و KYC](https://theypaid.io/blog/non-custodial-crypto-payment-gateway-guide-2026)

**TypeScript · MCP · Skill عامل · مجوز MIT**

## قابلیت‌ها

| بخش | کارهایی که عامل می‌تواند انجام دهد |
|---|---|
| حساب | ثبت‌نام، ورود و تکمیل ورود دومرحله‌ای |
| فروشگاه | مشاهده، ساخت، انتخاب، ویرایش، فعال‌سازی، غیرفعال‌سازی و حذف |
| کیف‌پول | اتصال نشانی عمومی یا xpub موجود؛ ساخت محلی و رمزگذاری‌شده برای دارایی‌های پشتیبانی‌شده |
| دارایی‌ها | مشاهدهٔ فهرست TheyPaid و مدیریت دارایی‌های فروشگاه |
| اعتبار خدماتی | مشاهدهٔ اعتبار، ساخت فاکتور شارژ و بررسی نتیجه |
| پرداخت | ساخت فاکتور یا لینک پرداخت واقعی، مشاهدهٔ جزئیات و پیگیری وضعیت |

## نصب

به Node.js نسخهٔ ۲۰ یا بالاتر نیاز دارید.

~~~sh
git clone https://github.com/plilian/crypto-payment-gateway-farsi.git
cd crypto-payment-gateway-farsi
npm install
npm run build
~~~

فایل اجرایی ساخته‌شده را در تنظیمات MCP میزبان خود با فرمان node و مسیر کامل dist/mcp/index.js ثبت کنید. گذرواژه‌ها و کلیدها را فقط با Secret Store میزبان تنظیم کنید؛ آن‌ها را در گفت‌وگو یا فایل پیکربندی مشترک قرار ندهید. راهنمای کامل در [نصب و راه‌اندازی](docs/SETUP.md) است.

### نصب Skill

فایل [راهنمای Skill](skill/theypaid/SKILL.md) را در پوشهٔ Skill محیط خود قرار دهید. Skill برای انجام کارها ابزارهای MCP را فراخوانی می‌کند.

## درخواست از عامل

- «TheyPaid را برایم راه‌اندازی کن و یک فروشگاه بساز.»
- «دارایی‌های قابل پشتیبانی را نشان بده و کیف‌پول بیت‌کوینم را وصل کن.»
- «برای این خدمت یک لینک پرداخت ۲۵ دلاری بساز.»
- «وضعیت این فاکتور را از TheyPaid بررسی کن.»
- «اعتبار خدماتی حسابم چقدر است؟»
- «تا تأیید پرداخت این فاکتور منتظر بمان.»

برای حساب تازه، پس از ثبت‌نام باید ایمیل تأیید TheyPaid را باز کنید. پیش از ثبت کیف‌پول یا ساخت پرداخت، عامل تأیید لازم را می‌گیرد.

## کیف‌پول و اعتبار خدماتی

ساخت کیف‌پول محلی برای ۱۳ دارایی فعلی فهرست فروشگاه TheyPaid فعال است: **BTC، BCH، LTC، BSV، GRAM، DOGE، TON_USDT، TRX، TRON_USDT، BNB، BSC_USDT، ETH** و **ETH_USDC**.

عبارت بازیابی و کلید خصوصی در فایل محلی رمزگذاری‌شده می‌مانند؛ برای اتصال به TheyPaid فقط دادهٔ عمومی کیف‌پول فرستاده می‌شود.

اعتبار خدماتی TheyPaid برای پرداخت کارمزد پردازش فاکتور است و با رمزارز موجود در کیف‌پول پذیرنده تفاوت دارد. اعتبار خوش‌آمدگویی ۱۰ دلاری برای حساب‌های واجد شرایط، اعتبار خدماتی است و به کیف‌پول رمزارز اضافه نمی‌شود.
