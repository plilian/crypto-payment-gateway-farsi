# ساخت فاکتور

پس از راه‌اندازی MCP و انتخاب فروشگاه، از عامل بخواهید:

> با دارایی فعال <assetId>، برای <description> یک فاکتور ۵۰ دلاری با تلورانس پذیرش صفر بساز.

عامل ابتدا دارایی‌های فعال فروشگاه را از TheyPaid می‌گیرد، سپس ابزار theypaid_create_invoice را با شناسهٔ همان دارایی اجرا می‌کند. پاسخ شامل شناسهٔ فاکتور و لینک پرداختی است که TheyPaid ساخته است. پیش از فرستادن لینک برای مشتری، مبلغ و دارایی را بررسی کنید.

اگر هنگام ساخت فاکتور پاسخی نرسید، درخواست را بی‌درنگ تکرار نکنید؛ ابتدا فهرست فاکتورهای فروشگاه را بررسی کنید تا فاکتور تکراری ساخته نشود.
